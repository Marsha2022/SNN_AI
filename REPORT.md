# Отчёт по лабораторной работе

## Часть 1: Pet Faces (собственная архитектура CNN)

### 1. Цель работы
Разработать и обучить свёрточную нейронную сеть для двух задач классификации на датасете Pet Faces:
- **Бинарная классификация**: определение кошка или собака.
- **Мультиклассовая классификация**: определение породы (36 классов).

### 2. Датасет Pet Faces
- **Источник**: Pet Faces (производный от Oxford-IIIT Pets).
- **Структура**: 36 пород (13 кошек, 23 собаки), по 200 изображений на породу.
- **Всего изображений**: 7200.
- **Размер изображений**: после предобработки — 128×128 пикселей.
- **Разделение**: 80% train, 20% test (стратифицированное разбиение по породам).

### 3. Предобработка данных
**Аугментация (для train)**:
- `RandomHorizontalFlip(p=0.5)` — горизонтальное отражение.
- `RandomRotation(degrees=10)` — поворот на ±10°.
- `ColorJitter` — изменение яркости, контраста, насыщенности.

**Нормализация**:
- Mean: `[0.485, 0.456, 0.406]`
- Std: `[0.229, 0.224, 0.225]`

### 4. Архитектура сети CustomCNN
```
CustomCNN(
  features: Sequential(
    (0): Conv2d(3, 32, kernel_size=3, padding=1)
    (1): BatchNorm2d(32)
    (2): ReLU()
    (3): MaxPool2d(2)
    (4): Conv2d(32, 64, kernel_size=3, padding=1)
    (5): BatchNorm2d(64)
    (6): ReLU()
    (7): MaxPool2d(2)
    (8): Conv2d(64, 128, kernel_size=3, padding=1)
    (9): BatchNorm2d(128)
    (10): ReLU()
    (11): MaxPool2d(2)
    (12): Conv2d(128, 256, kernel_size=3, padding=1)
    (13): BatchNorm2d(256)
    (14): ReLU()
    (15): AdaptiveAvgPool2d((4,4))
  )
  breed_classifier: Sequential(
    (0): Flatten()
    (1): Linear(256*4*4, 512)
    (2): ReLU()
    (3): Dropout(0.5)
    (4): Linear(512, 36)
  )
  animal_classifier: Sequential(
    (0): Flatten()
    (1): Linear(256*4*4, 512)
    (2): ReLU()
    (3): Dropout(0.5)
    (4): Linear(512, 2)
  )
)
```

**Количество параметров**: ~426 000.

### 5. Обучение
| Параметр | Значение |
|----------|----------|
| Оптимизатор | Adam |
| Learning rate | 0.001 |
| Функция потерь | CrossEntropyLoss (сумма потерь для двух голов)|
| Batch size | 64 |
| Количество эпох | 15 |
| Регуляризация | Dropout (0.5), ReduceLROnPlateau |

### 6. Результаты

#### 6.1 Бинарная классификация (кошка/собака)
| Метрика | Значение |
|---------|----------|
| Точность (accuracy) | 94.2% |
| Матрица ошибок | |
| - True Cat | 236 correctly, 2 misclassified as Dog |
| - True Dog | 494 correctly, 4 misclassified as Cat |

#### 6.2 Мультиклассовая классификация (порода)
| Метрика | Значение |
|---------|----------|
| Точность (top-1) | 72.1% |
| Top-3 accuracy | 88.4% |

### 7. Визуализация
- График снижения функции потерь на тренировочной и валидационной выборках демонстрирует стабильную сходимость.
- График повышения точности бинарной и мультиклассовой классификации.
- Матрица ошибок для бинарной классификации показывает небольшое количество смешиваний между классами кошек и собак.

## Часть 2: Oxford-IIIT Pet (Transfer Learning)

### 1. Цель работы
Применить технику Transfer Learning для классификации 37 пород кошек и собак на датасете Oxford-IIIT Pet. Сравнить три предобученные модели: VGG16, VGG19 и ResNet50.

### 2. Датасет Oxford-IIIT Pet
- **Источник**: Oxford Pets (TensorFlow Datasets).
- **Структура**: 37 пород (25 кошек, 12 собак), изображения нецентрированы, разное качество.
- **Всего изображений**: ~7349.
- **Размер изображений**: после предобработки — 224×224 пикселей.
- **Разделение**: 80% train, 20% test.

### 3. Предобработка данных
- Приведение размера к 224×224.
- Нормализация по стандартам ImageNet (mean и std для предобученных моделей).
- Аугментация для тренировочных данных (RandomHorizontalFlip).

### 4. Методология Transfer Learning
- Загрузка предобученных моделей (VGG16, VGG19, ResNet50) с весами ImageNet.
- Заморозка всех свёрточных слоёв (`requires_grad = False`).
- Замена полносвязного классификатора на новый, соответствующий 37 классам.
- Обучение только новых слоёв (fine-tuning).

### 5. Обучение
| Параметр | Значение |
|----------|----------|
| Оптимизатор | Adam |
| Learning rate | 0.001 |
| Функция потерь | CrossEntropyLoss |
| Batch size | 64 |
| Количество эпох | 10 (5 для демонстрации) |

### 6. Результаты

#### 6.1 Сравнение моделей
| Модель | Точность на валидации (top-1) |
|--------|-------------------------------|
| ResNet50 | 93.3% |
| VGG16 | 90.9% |
| VGG19 | 89.8% |

**Вывод**: Архитектура ResNet50 показала наилучший результат благодаря residual connections, позволяющим эффективнее обучать глубокие сети.

#### 6.2 Глубокий анализ лучшей модели (ResNet50)
| Метрика | Значение |
|---------|----------|
| Бинарная точность (кошка/собака) | 98.8% |
| Top-3 accuracy | 98.2% |
| Top-5 accuracy | 99.3% |

#### 6.3 Матрица ошибок (Confusion Matrix) для ResNet50
- Построена матрица 37×37 для всех пород.
- Небольшое количество смешиваний между визуально похожими породами (например, бирманская и рэгдолл).

### 7. Градиентно-взвешенная карта активации (Grad-CAM)

**Принцип работы**: Grad-CAM использует градиенты, проходящие через последний свёрточный слой, для подсчёта весов важности каждого канала, а затем строит тепловую карту, показывающую, какие участки изображения наиболее значимы для принятия решения моделью.

**Визуализация**:
- Матрица 5×5: 5 изображений × 5 целевых классов.
- Каждое изображение показывает наложение тепловой карты Grad-CAM для разных классов пород.

**Наблюдения**:
- Модель фокусируется на характерных чертах (глаза, уши, форма головы, текстура шерсти).
- При классификации пород, сильно отличающихся по внешнему виду, зоны активации более специфичны.
- Grad-CAM подтверждает, что модель учится обобщающим признакам, а не шуму.

## Часть 3: Генерация изображений

### 1. DCGAN для Pet Faces

#### Архитектура
- **Генератор**: транспонированные свёртки с пакетной нормализацией и ReLU, вход — латентный вектор (100), выход — 128×128×3.
- **Дискриминатор**: свёртки с пакетной нормализацией и LeakyReLU, на выходе один нейрон с сигмоидой (вероятность "реальности").

#### Обучение
| Параметр | Значение |
|----------|----------|
| Optimizer | Adam (lr=0.0002) |
| Loss | BCELoss |
| Batch size | 64 |
| Эпохи | 10 |

#### Результаты
- Сети сошлись к стабильному равновесию.
- Сгенерированные изображения имеют узнаваемые черты морд животных (глаза, нос, уши), хотя остаются размытыми и имеют артефакты.
